How it works

The orbit is the decoder.

01 · Orbit

Know the light

Every satellite's orbit is public. From it we know, for each frame, whether the satellite was in sunlight or in Earth's shadow, and where it was.

02 · Bytes

Find what reacts

Every way of reading the bytes is tested. Batteries charge in sunlight, panels cool in the dark, counters tick, GPS traces the orbit. Whatever follows the physics is a field.

03 · Claude

Name it

Claude reads each field's evidence like a spacecraft engineer and gives it a name, a unit and a scale. It never sees the satellite's name or its decoder.

Graded blind against real decoders

  
Some satellites already have a published decoder, so every answer can be checked. Shadowfield runs on their raw frames as if
    no decoder existed. Only afterwards is its output compared with the decoder.
